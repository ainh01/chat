# 🐛 Bug Fixes: Unsend, Reactions, and GraphQL Query  

## Bug 1: Unsend Message - Missing Field Resolver  

**Root Cause:** The `meta` field contains snake_case keys from MongoDB (`is_unsent`, `is_forwarded`, etc.) but GraphQL schema expects camelCase (`isUnsent`, `isForwarded`).  

### Fix: Add `meta` field resolver  

**File:** `src/graphql/resolvers/conversationResolver.js`  

**FIND this section (around line 60):**  

```javascript  
  Message: {  
    content(parent) {  
      if (parent.meta?.is_unsent) {  
        return null;  
      }  
      return parent.content;  
    },  

    id(parent) {  
      return parent._id.toString();  
    },  
```  

**ADD this resolver after `timeSent` (around line 85):**  

```javascript  
    timeSent(parent) {  
      return parent.time_sent;  
    },  

    // ========== FIX: Transform meta fields from snake_case to camelCase ==========  
    meta(parent) {  
      if (!parent.meta) {  
        return {  
          isUnsent: false,  
          isForwarded: false,  
          replyTo: null,  
          lastEditAt: null  
        };  
      }  

      return {  
        isUnsent: parent.meta.is_unsent || false,  
        isForwarded: parent.meta.is_forwarded || false,  
        replyTo: parent.meta.reply_to || null,  
        lastEditAt: parent.meta.last_edit_at || null  
      };  
    },  

    reactions(parent) {  
      if (!parent.reactions || !Array.isArray(parent.reactions)) {  
        return [];  
      }  

      return parent.reactions.map(reaction => ({  
        userId: reaction.user_id,  
        type: reaction.type  
      }));  
    },
```  

## Bug 2: Add Reaction - Missing Pipeline Option  

**Root Cause:** `Message.updateOne()` doesn't accept aggregation pipeline syntax (array) by default in Mongoose 6+.  

### Fix: Add `{ timestamps: false }` option to enable pipeline  

**File:** `src/graphql/resolvers/conversationResolver.js`  

**FIND (around line 686):**  

```javascript  
      // Atomic update: remove old reaction + add new reaction  
      await Message.updateOne(  
        { _id: message._id },  
        [  
          {  
            $set: {  
              reactions: {  
                $concatArrays: [  
                  {  
                    $filter: {  
                      input: '$reactions',  
                      cond: { $ne: ['$$this.user_id', user.id] }  
                    }  
                  },  
                  [{ user_id: user.id, type: reactionType }]  
                ]  
              }  
            }  
          }  
        ]  
      );  
```  

**REPLACE WITH:**  

```javascript  
      // Atomic update: remove old reaction + add new reaction  
      await Message.updateOne(  
        { _id: message._id },  
        [  
          {  
            $set: {  
              reactions: {  
                $concatArrays: [  
                  {  
                    $filter: {  
                      input: '$reactions',  
                      cond: { $ne: ['$$this.user_id', user.id] }  
                    }  
                  },  
                  [{ user_id: user.id, type: reactionType }]  
                ]  
              }  
            }  
          }  
        ],  
        { timestamps: false }  // ← ADD THIS to enable aggregation pipeline  
      );  
```

## Bug 3: Forward Message - Client Query Syntax Error  

**Root Cause:** This is a **client-side error**, not a server bug. GraphQL requires specifying subfields for object types.  

### Fix: Update Client Query  

**WRONG:**  
```graphql  
mutation {  
  forwardMessage(  
    messageId: "SOURCE_MESSAGE_ID"  
    toConversationId: "TARGET_CONVERSATION_ID"  
  ) {  
    id  
    content  
    senderId  
    meta {  
      isForwarded  
      replyTo  
    }  
    reactions  # ❌ ERROR: Must specify subfields  
  }  
}  
```  

**CORRECT:**  
```graphql  
mutation {  
  forwardMessage(  
    messageId: "674acc3e7c7427cfdb987654"  
    toConversationId: "674acc3e7c7427cfdb423456"  
  ) {  
    id  
    content  
    senderId  
    meta {  
      isForwarded  
      replyTo  
    }  
    reactions {  # ✅ FIXED: Added subfields  
      userId  
      type  
    }  
  }  
}  
```
